# dsh-meter

DeepSeek Harness Web 的用量计费展示插件：在输入框上方右侧显示三个单行胶囊。

| 胶囊 | 内容 |
| --- | --- |
| 时段 | `高峰 09:00-12:00` / `低峰 18:00-24:00`（北京时间，每 30 秒自动切换，高峰橘黄高亮） |
| 消费 | `消费 ¥x.xxxx`（悬停见分模型/分时段明细、缓存命中率） |
| 余额 | `余额 ¥x.xx` + 币种（每 5 分钟自动刷新） |

## 计费口径

- 高峰时段：北京时间 09:00-12:00、14:00-18:00；其余为低峰（半价）。
- 单价表为官方价目（v4-flash / v4-pro × 缓存命中/未命中/输出 × 峰/谷，元/百万 token）。
- 每个请求按其**当时所用模型 × 当时峰谷时段**分别计价，切换模型不会重定价历史用量。
- 消费为估算值，以官方账单为准。

## 安装

```bash
# 需要 pnpm（dsh plugin 用它管理 profile 插件）
dsh plugin --profile web add https://github.com/Rieide/dsh-meter.git
```

首次安装后需在插件设置中授权该插件（浏览器端 UI）。

余额查询依赖 `DEEPSEEK_API_KEY`：在 Web 的 Models 设置页写入，或启动环境导出该变量。

## 开发

```bash
node scripts/build.mjs   # 生成 lib/ 产物（纯 JS，无编译步骤）
```
